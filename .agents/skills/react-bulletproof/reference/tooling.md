# Lint, format, hooks

Copy `templates/.oxlintrc.json` and `templates/prettier.config.js` into the project root.

## oxlint

```json
{
  "$schema": "./node_modules/oxlint/configuration_schema.json",
  "plugins": ["react", "typescript", "unicorn", "import"],
  "categories": { "correctness": "error" },
  "rules": {
    "react/purity": "off",
    "react/set-state-in-effect": "off",
    "react/refs": "off",
    "react/immutability": "off",
    "react/incompatible-library": "off",
    "react/preserve-manual-memoization": "off",
    "react/static-components": "off",
    "react/use-memo": "off"
  },
  "ignorePatterns": ["public/**"],
  "overrides": [
    {
      "files": ["src/components/ui/**/*.ts", "src/components/ui/**/*.tsx"],
      "rules": {
        "no-shadow": "off",
        "react-hooks/exhaustive-deps": "off",
        "eslint/no-unused-vars": "off"
      }
    }
  ]
}
```

- Only the `correctness` category is enforced, as errors. React Compiler-style rules are off (the codebase does not use the compiler).
- shadcn-generated `src/components/ui/**` is relaxed, never hand-fixed.
- Fix code instead of adding inline disables. If a disable is unavoidable, scope it to one line with a reason.

## prettier

```js
//  @ts-check

/** @type {import('prettier').Config} */
const config = {
  semi: false,
  singleQuote: true,
  trailingComma: 'all',
  printWidth: 80,
}

export default config
```

- Long generic class signatures may opt out with `// prettier-ignore` on the class (see builders/emitters) so each method signature stays on one line.
- Keep `.prettierignore` for generated files (route tree, i18n registry, dist).

## package.json scripts

```json
{
  "build": "vite build && tsc",
  "test": "vitest run",
  "lint": "oxlint",
  "format": "prettier",
  "check": "prettier . --write --experimental-cli && oxlint --fix",
  "prepare": "husky"
}
```

## Husky

`.husky/pre-commit`: prettier `--write` on staged js/jsx/ts/tsx/json/css/md and re-add, `npx oxlint`, warn on new logic files without a test, `npx vitest related --run --passWithNoTests <staged ts files>`.
`.husky/pre-push`: `npm run build`.

## Definition of done

- `npm run build` passes (vite + `tsc`).
- `npm run test` passes; new or changed logic has its test.
- `npm run check` leaves no diff and no lint errors.
- Generated files regenerated by script, not hand-edited.
